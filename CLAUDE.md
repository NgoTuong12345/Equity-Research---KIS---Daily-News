## What This Repo Does

Twice-daily automation pipeline for Vietnamese financial news:
1. **Python scraper** (`vietnam_news_scraper/`) collects news from RSS feeds, web scraping, and Selenium (FireAnt) → outputs `vietnam_financial_news_combined_YYYYMMDD_HHMM.csv`
2. **Node.js uploader** (`google-sheets-uploader/`) reads the latest CSV, launches Chrome via CDP, and writes data into a new Google Sheets tab
3. **Report generator** (`google-sheets-uploader/generate-report.js`) reads human-selected URLs (TAKE) from the sheet and writes a markdown report to `reports/`
4. **Task Scheduler** triggers `run-morning.bat` (7:55 AM) and `run-afternoon.bat` (3:00 PM) Vietnam time

## Running the Scripts

```powershell
# Run upload manually (morning or afternoon)
cd google-sheets-uploader
node upload-to-sheets.js morning
node upload-to-sheets.js afternoon

# Generate markdown report after human review
node generate-report.js morning
node generate-report.js afternoon

# Run the Python scraper only
cd vietnam_news_scraper
call run.bat

# Full pipeline (scraper + upload)
call run-morning.bat
call run-afternoon.bat
```

## Chrome Launch Pattern

Both JS scripts use the same approach — **Chrome cannot use `launchPersistentContext` with the default profile** because Chrome blocks Playwright's `--remote-debugging-pipe` flag on the default profile. The workaround:

1. `taskkill /F /IM chrome.exe` to kill any running Chrome
2. Delete `SingletonLock`, `SingletonCookie`, `SingletonSocket` from the user data dir
3. Launch Chrome via `PowerShell Start-Process` with `--remote-debugging-port=9222`
4. Poll `chromium.connectOverCDP('http://127.0.0.1:9222')` until ready (up to 20s)
5. Use `browser.contexts()[0]` as the context

Use `127.0.0.1` not `localhost` — Playwright resolves `localhost` to `::1` (IPv6) but Chrome listens on IPv4.

## Google Sheets Column Layout

Each session tab (`mor_DD_MM_YYYY` / `after_DD_MM_YYYY`) has 10 columns:

| Col | Name | Source |
|---|---|---|
| A | `news_date` | CSV |
| B | `news_time` | CSV |
| C | `news_source` | CSV |
| D | `news_category` | CSV |
| E | `news_corp_select` | **Manual** — human types `TAKE` |
| F | `news_poli_select` | **Manual** — human types `TAKE` |
| G | `news_titles` | CSV |
| H | `news_urls` | CSV |
| I | `corp_url` | Formula: `=IF(E2="TAKE",H2,"")` |
| J | `poli_url` | Formula: `=IF(F2="TAKE",H2,"")` |

## Google Sheets Selector Notes

The UI is in **Vietnamese locale**, so:
- Add Sheet button: `[aria-label="Thêm trang tính"]` (not "Add Sheet")
- Active tab: `.docs-sheet-active-tab`
- Tab names: `.docs-sheet-tab-name`
- Name box (cell navigator): `.waffle-name-box` — use `{ force: true }` to bypass `modal-dialog-bg` overlay that persistently intercepts pointer events on public sheets

Tab names: Google Sheets auto-capitalises the first letter (script creates `mor_...` but it displays as `Mor_...`). Tab existence checks use `.toLowerCase()` to handle this.

## Python Scraper

`vietnam_news_scraper/main.py` scrapes RSS feeds + BeautifulSoup sources in parallel threads, then uses **Selenium + ChromeDriverManager** for FireAnt (requires Chrome). Output CSV columns: `date, time, source, category, title, link`. The `run.bat` bootstraps a local `venv` and installs from `requirements.txt` on first run.
